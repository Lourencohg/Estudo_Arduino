# :factory: Estudo_Arduino

Repositório pessoal e central de conhecimento dedicada aos meus estudos, anotações e projetos práticos com a plataforma de prototipagem eletrônica Arduino, Baseando-se principalmente no livro [30 projetos com Arduino](https://www.amazon.com.br/Projetos-com-Arduino-Simon-Monk/dp/858260162X).

O intuito deste é documentar evolução técnica, centralizar referências bibliográficas e servir como portfólio para os projetos desenvolvidos ao longo da graduação e pesquisas independentes.
